# Product naming review

Review date: August 17, 2026. This is a confusion check, not trademark clearance or legal advice.

“Reader” is highly generic and already associated with multiple reading products. Current examples include [Readwise Reader](https://docs.readwise.io/reader/docs/faqs), the historical [Microsoft Reader](https://en.wikipedia.org/wiki/Microsoft_Reader), and newer local-first products such as [Readest](https://readest.com/blog/introducing-readest) and [Orrery](https://ekinteractive.com/product/orrery.html). Search results also include many unrelated PDF/document “Reader” products.

## Recommendation

- Keep the owner-confirmed `Reader` repository/product name and application identifier unchanged for this public-source alpha; renaming now would create needless migration and artifact churn.
- Use the differentiating display line **“Reader — a local-first reading library”** in repository and recruiter drafts.
- Do not claim the generic word is available, unique, or protectable.
- Before broad public promotion or a stable installer, reconsider a distinctive final name after repository, domain, package, Microsoft Store, and appropriate trademark searches.
- Do not change `app.reader.localfirst`, repository name, executable identity, or public metadata without explicit approval.
