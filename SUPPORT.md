# Support and privacy-safe diagnostics

Reader `0.1.0-alpha.4` is private and unpublished, so there is no public support commitment or public download channel.

For an authorized private review, provide:

1. Reader version and whether it was the browser preview, local executable, or local NSIS install.
2. Windows version, display scaling, and WebView2 version if known.
3. The general format and approximate size of the input without giving its title, filename, or creator.
4. Minimal reproduction steps, expected behavior, and the exact visible Reader error after removing filenames and paths.
5. Whether the problem remains after restarting Reader.

Do not provide a real publication, protected-media sample, activation or account data, library export, private annotation, reading history, personal path, user profile, credential, certificate, or unrestricted log. Reproduce import problems with an original synthetic fixture and inspect every screenshot for private titles, notifications, usernames, and unrelated windows.

Reader does not currently create an automated support bundle. Do not copy the WebView profile or IndexedDB database into a report. Security-sensitive findings belong in the private route described in [Security](SECURITY.md), never a public issue.
